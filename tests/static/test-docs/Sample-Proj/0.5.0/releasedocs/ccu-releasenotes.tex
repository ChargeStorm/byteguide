    \verb|StartTransaction.conf|.

    start time 0.

  \end{itemize}
\item For dual 1-phase CSR100 and Chargestorm Connected (1), the conversion to

\item WebUI: Fix the CTEK NGHome configuration profile.

\section{Version: r3.12}
Date of release 2020-05-14

\subsection*{What is new?}

\begin{itemize}
\item Support for the new \nanogrid\ controller, CGC500.
\item Documentation for error codes has been added to the release package.
\item OCPP 1.5 has been removed.
\item The upgrade file will only install if the protocol is set to
  \verb|NONE| or to OCPP 1.6J.
\item OCPP 1.6:
  \begin{itemize}
  \item Working reservation support. A reserved EVSE indicates this by a
    pulsating green LED.
  \item BootNotification.req will include a ``v2'' in the model name for
    Chargestorm Connected 2.
  \item Added limitations for max stack level and max periods in a charging
    profile. Violations will result in a \verb|CALLERROR|.
  \item Added limitations for the size of the local list, as well as the
    number of tokens that can be sent in a single \verb|SendLocalList|.
  \item Add the key to inform the CSMS of the supported file transfer
    protocols.
  \end{itemize}
\item The timeout that invalidated an EVSE if an EV was connected but never
  authorized has been removed. See comment under ``Fixed'' for info on how the
  stations handles two EV's connected but not authorized.
\end{itemize}

\subsection*{What is changed?}

\begin{itemize}
\item OCPP 1.6:
  \begin{itemize}
  \item The Charging Station will only send Heartbeat.req's if there's been no
    other OCPP communication for a whole Heartbeat interval. However, there
    will be at least one Heartbeat.req every 24h.
  \item Removed the measurand \verb|Power.Offered|; this wasn't actually
    supported before.
  \end{itemize}
\item Web-configuration interface:
  \begin{itemize}
  \item The log page has been removed; it wasn't working.
  \item The status page will now list the model.
  \end{itemize}

\end{itemize}

\subsection*{What is fixed?}

\begin{itemize}
\item OCPP 1.6:
  \begin{itemize}
  \item When using a modem, ensure that the ICCID and IMSI is read prior to
    sending a BootNotification.req. This might delay sending the boot
    notification by a short time.
  \item Correctly handle \verb|ChangeAvailability.req| again, including
