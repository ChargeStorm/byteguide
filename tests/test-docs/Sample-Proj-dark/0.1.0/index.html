    About

    This repository is intended to use as a template for creating new python repositories. It contains the basic structure and configuration files required for a python repository with all the latest tools for following best practices.

    Features

    This section describes the features of the repository and how to use them.

    Uv

    Uv is a package manager for python projects which provide lock file support and python version management. It's written in Rust and is faster than other package managers like pipenv, poetry, etc.

    📢 NOTE

    It's usually recommended to pin the lowest python version that the project supports in the .python-version file.

    Install uv using the following command:

    curl -LsSf https://astral.sh/uv/install.sh | sh

    Then run the following command to install the dependencies:

    uv sync

    This will install all package and dev dependencies, as well as the python version specified in the pyproject.toml file to a .venv virtual environment in the root of the project.

    To add a new dependency, run the following command:

    # To add a dependency
uv add <package_name>

# To add a dev dependency
uv add --dev <package_name>

    For more information, visit the uv documentation.

    Pre-commit

    Pre-commit is a framework for managing and maintaining multi-language pre-commit hooks. It's written in Python and is widely used in the python community.

    We choose to use the pre-commit-uv version of pre-commit, which is a fork of the original pre-commit but uses uv as a package manager. Meaning all packages are installed in parallel, significantly reducing the time it takes to install the packages.

    After running uv sync, pre-commit will be installed in the .venv virtual environment. To install the pre-commit hooks, run the following command:

    uv pre-commit install

    This will install the pre-commit hooks in the .git/hooks directory, and the hooks will be called on staged files for each commit.

    To run the pre-commit hooks manually on all files, run the following command:

    uv pre-commit run --all-files

    For more information, visit the pre-commit documentation.

    Testing

    Testing is done using the pytest framework. To run the tests, execute the following command:

    uv run pytest

    The pyproject.toml file contains the configuration for the pytest framework. This includes coverage configuration which will output code coverage percentage per file for the src/ directory in the terminal. It will also generate a HTML report in the htmlcov/ directory.

    To see line by line coverage, open the htmlcov/index.html file in a browser.

    Documentation

    Documentation is built using mkdocs-material. To build the documentation, run the following command:

    uv run mkdocs build

    This will build the documentation in the site directory. To serve the documentation locally, run the following command:

    uv run mkdocs serve

    📢 NOTE

    The README.md file has been symlinked to the docs/index.md file to be used as the index page for the documentation. This is not a requirement, but it's a conventiant way to keep the README.md file up to date with the documentation.

    Command to create a symlink: ln -s ../README.md docs/index.md, executed from the root of the project.

    Extra CTEK styling

    Extra CTEK logo and color styling is added to the documentation. The logo resides in the docs/assets. The color styling is added to the docs/stylesheets/extras.css file. Both are included in the mkdocs.yml configuration file.
